# 本地查看 shadcn-admin

只想看界面时，先打开 [官方 Demo](https://shadcn-admin.netlify.app/)。需要查看固定源码、比较原版交互或离线修改时，再使用本地项目。

## 环境与版本

2026-10-23 已验证 Node.js `v26.3.0`、pnpm `10.11.0`，固定提交见 [UPSTREAM.md](../UPSTREAM.md)。这是实际使用的环境记录，不表示只支持这些版本。此次未升级依赖，安装使用锁文件并跳过依赖安装脚本，生产构建成功；Node 的 `module.register` 弃用提示未阻止构建。

已有本仓时直接进入仓根，无需再克隆。另一台电脑可从 [个人 Fork](https://github.com/haers/zhao-shadcn-admin) 获取；精确重现原版代码时，按 UPSTREAM 中的完整 SHA 核对，不以包版本或同名标签替代。

## 安装与构建

在仓根执行：

```sh
node --version
pnpm --version
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 pnpm install --frozen-lockfile --ignore-scripts
pnpm build
```

本次安装全部复用了本机包缓存；其他机器可能需要联网下载依赖。上述命令不下载测试浏览器。`--ignore-scripts` 是本次已验证的安装方式，升级后如果某项依赖明确需要脚本，应先核对该依赖再定向处理。

`node_modules/`、`dist/` 属于可重建产物，已被忽略；仓库按轻量源码保留，需要运行时再安装即可。

## 启动与停止

```sh
pnpm dev --host 127.0.0.1 --port 8361 --strictPort
```

打开 <http://127.0.0.1:8361/>。端口 `8361` 仅为本次试用选择；`--strictPort` 会在端口被占用时报错，避免悄悄切换地址。查看占用可运行 `lsof -nP -iTCP:8361 -sTCP:LISTEN`，确认后另选空闲端口，不关闭其他项目进程。

结束查看时在启动终端按 `Ctrl+C`，无需配置常驻服务。需要检查生产构建时执行：

```sh
pnpm build
pnpm preview --host 127.0.0.1 --port 8361 --strictPort
```

`preview` 是构建产物查看入口；本次实际交互试用使用的是 `dev`。

## 可以先看哪些页面

| 页面 | 看点 | 数据边界 |
| --- | --- | --- |
| `/` | 后台壳、统计卡片、图表 | 演示统计 |
| `/tasks` | 搜索、筛选、表格与空态 | 上游样例任务 |

普通示例页的本次试用没有配置真实账号。Clerk 相关页面需单独配置与验证，不应为看普通样例填入生产凭据。示例表单不要填写真实密码或个人数据。

## 常见问题

- **引擎版本报错**：先核对当前 Node 与锁文件依赖的要求，使用独立版本环境；不要直接删除锁文件或批量升级包。
- **安装网络失败**：检查包源和当前网络配置；不要把含凭据的代理地址或私有配置写入源码、截图和问题反馈。
- **新增用户后没有保存**：这是样例提交行为，接入真实服务需要业务开发，详见 [实际使用](实际使用.md)。
- **手机表格显示不全**：本次 390 px 视口下需横向查看右侧列；筛选提示也有截短，不以无整页溢出代替移动端体验验收。
- **要做自动化浏览器检查**：先确认项目的测试配置和可用浏览器。普通界面查看无需额外安装测试浏览器；自动化环境按实际需要单独准备。
